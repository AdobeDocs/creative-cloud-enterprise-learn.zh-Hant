# Bullet Time VFX

瞭解如何饋送主圖產品或主圖影像，以產生圍繞著主圖產品或主圖影像的旋轉角度序列，然後自動拼接凍結影格掃描。 [開啟Bullet Time VFX範本](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:US:3efb4f51-345d-58eb-b7c8-7b289f0dd1c4)。

[!BADGE 產業範例]{type=Informative tooltip="產業範例"}

* **戶外** — 在位置沒有多部攝影機的情況下，為登山者製作付費社交廣告的動作中主圖子彈時刻。
* **零售** — 為產品上市頁面建立新運動鞋的360度凍結影格快照。
* **汽車** — 為數位陳列室製作旋轉式車輛主圖快照，而不使用可旋轉的工作室會議。

>[!TIP]
>
>**開始之前** — 為獲得最佳結果，請根據您自己的品牌、產品和工作流程自訂此範本。 在使用任何輸出之前，交換參考影像、提示和複製。
