# 設計系統產生器

瞭解如何根據網站熒幕擷圖產生設計系統。 圖形會在單一批次執行中產生一組相符的圖示、圖樣和版面配置元件。 [開啟設計系統產生器](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:US:b40cd34c-66b2-586c-ab4a-5595490cded6)。

[!BADGE 產業範例]{type=Informative tooltip="產業範例"}

* **技術** — 為每季的功能推出產生可重複使用的圖示和背景模式，可跨廣告、登陸頁面和社交重複使用，無需重新簡報設計。
* **財務** — 在開發開始之前，為新應用程式重新設計建置一致的圖示和色彩系統。
* **通訊與電信** — 為跨網路和店內招牌的新計畫層級產生相符的視覺語言。

>[!TIP]
>
>**開始之前** — 為獲得最佳結果，請根據您自己的品牌、產品和工作流程自訂此範本。 在使用任何輸出之前，交換參考影像、提示和複製。
