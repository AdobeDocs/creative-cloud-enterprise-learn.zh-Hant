# 即時著色器

瞭解如何從影像開始，並套用三種不同的自訂著色器以及即時預覽結果。 直接在節點上調整著色器引數，而非從頭開始重新演算。 [開啟即時著色器範本](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:US:51848c67-e360-5c40-8eff-8517b3395d54)。

[!BADGE 產業範例]{type=Informative tooltip="產業範例"}

* **技術** — 建立自訂風格化著色器，尋找用於互動式貿易展覽示範中的3D產品組態程式。
* **汽車** — 在實體原型存在之前，在車輛模型上預覽自訂油漆和材質著色器。
* **零售** — 測試樣式的材料會在3D產品轉譯器上尋找數位架顯示器。

>[!TIP]
>
>**開始之前** — 為獲得最佳結果，請根據您自己的品牌、產品和工作流程自訂此範本。 在使用任何輸出之前，交換參考影像、提示和複製。
