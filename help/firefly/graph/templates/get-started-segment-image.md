# 快速入門 — 劃分影像

瞭解如何載入任何來源影像並執行分段節點，將主旨與其背景隔離。 [開啟快速入門 — 分割影像範本](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:VA6C2:c090820d-b733-44c7-910d-5e216c19c5cc)。

[!BADGE 產業範例]{type=Informative tooltip="產業範例"}

* **健康情況** — 將醫療裝置從繁忙的工作室鏡頭中分割出來，將其拖放到乾淨的臨床背景中，以供產品頁面使用，而不需要背景重新掃描。
* **零售** — 將服裝與生活風格像片隔離，以建立純淨產品的目錄影像。
* **汽車** — 將車輛從拍攝位置剪下，放在攝影棚背景中列印。

>[!TIP]
>
>**開始之前** — 為獲得最佳結果，請根據您自己的品牌、產品和工作流程自訂此範本。 在使用任何輸出之前，交換參考影像、提示和複製。
